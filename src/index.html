Cómo jugar

Pulsa Izquierda / Derecha o A / D para desplazarte con inercia.

Usa Arriba, W o Espacio para saltar. Las paredes no se pueden subir sin saltar.

Recoge la llave dorada y cruza el portal para avanzar. Tienes tres vidas por sector y vuelves al primero si se agotan.

Pulsa P o usa los botones para pausar, reanudar y finalizar.
